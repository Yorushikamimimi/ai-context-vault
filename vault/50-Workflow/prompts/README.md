# Prompts

## Purpose

Store reusable prompts here. Do not store daily conversation summaries here.

## Files

| File | Purpose |
|---|---|
| `web-conversation-summary-template.md` | Template for web AI tools that cannot write local files |
| `cross-tool-handoff.md` | Manual, read-only-first cross-tool recovery and acceptance prompts |
| `delegation-task-card.md` | Two-sided delegation card for mechanical, analysis, or research tasks |
| `quick-capture-agent.md` | Verbatim staging agent prompt for lightweight mobile or web capture |
