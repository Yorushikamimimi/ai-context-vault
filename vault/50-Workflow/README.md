# Workflow

This directory holds collaboration rules and reusable templates. It is not the default source of truth for every project or domain.

## Main files

| File or directory | Purpose |
|---|---|
| `COLLABORATION.md` | shared working rules for every AI tool; agent entry files point here |
| `AI_USAGE.md` | concise guidance for common AI collaboration requests |
| `SYNC_RULES.md` | decides where meaningful updates belong |
| `conversation-handoff.md` | source-first handoff and cross-tool acceptance gates |
| `prompts/cross-tool-handoff.md` | minimal source, coordinator, and responsibility prompts |
| `advanced/` | optional practices: multi-tool sharing, weekly summaries, execution records, close-out and commits, idea backlog |
| `task-memory/` | one lightweight current note only when no other owner exists |
| `logs/` | important dated history; not a current-state owner |
| `daily.md` | optional personal daily-review template |
| `prompts/` | reusable prompts, not chat archives |

## Rules

- Read `SYNC_RULES.md` before a meaningful write.
- Let project documents own project progress; do not clone them into task memory.
- Use weekly logs for important milestones, not for every conversation.
- A conversation handoff begins with source-of-truth paths. An old chat is only a gap-filling source.
