# Important Weekly Logs

This directory is a dated historical layer. Use it for important milestones, not every conversation and never as the only owner of a current fact.

Create a weekly entry from `weekly-log-template.md` when a decision, artifact, verification result, failure, or change of direction needs a durable timeline. The related domain or project document still owns the present state. For long weeks, an optional summary at the top keeps recovery short; see `../advanced/weekly-summary.md`.
